# 30-Assembly-Instructions

The site assembly guide for two people with one 5 mm hex key:

- **[100000_P04_POD-ASSEMBLY-GUIDE_INS.md](100000_P04_POD-ASSEMBLY-GUIDE_INS.md)** (DRAFT): 22 numbered steps with parts, fasteners, who holds what, time per step, safety notes and the final check.

It is generated by `v2/07-Packaging/pack.py` from `v2/07-Packaging/templates/assembly-guide.md`, from the same list of pieces as the packing plan, so labels, steps, bolt counts and times always agree. Edit the template or the script, never the guide itself. Step pictures from the Fusion model are added as each part's CAD lands.
