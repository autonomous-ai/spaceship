# 30-Assembly-Instructions

The site assembly guide for two people with one 5 mm hex key:

- **[100000_P04_POD-ASSEMBLY-GUIDE_INS.md](100000_P04_POD-ASSEMBLY-GUIDE_INS.md)** (DRAFT): 22 numbered steps with parts, fasteners, who holds what, time per step, safety notes and the final check.

It is generated by `v2/07-Packaging/pack.py` from `v2/07-Packaging/templates/assembly-guide.md`, from the same list of pieces as the packing plan, so labels, steps, bolt counts and times always agree. Edit the template or the script, never the guide itself. Each step's picture comes from the Fusion model (below); pictures of the real parts replace them as each part's CAD lands.

**Step pictures.** `step_pictures.py` makes one picture per step from the Fusion model: it opens the skeleton's cloud design (a STEP import drops the body names), refuses when that design is already open, shows the bodies fitted so far (the step's new ones solid, the earlier ones faded), saves `img/100000_P04_POD-ASSEMBLY-GUIDE-STEP-NN_IMG.png` and closes the design without saving; then `pack.py` puts each picture under its step. It needs the Mac's screen unlocked and runs only through the Fusion runner:

```sh
python3 tools/fusion/run_script.py v2/02-Drawings/30-Assembly-Instructions/step_pictures.py --label "Packing and Assembly Engineer"
python3 v2/07-Packaging/pack.py
```

`100000_P04_POD-ASSEMBLY-GUIDE-STEP-BODIES_DATA.json` (written by `pack.py`) says which skeleton bodies each step adds; check K12 keeps it complete.
