Where each part BASE designs lives in the native files and what drives it (guideline §4.5). One native design holds the whole sample: `110000_P01_BASE_CAD.f3d` here, and the same design in the cloud at Default Project / FocusPod v2 / `110000_P01_BASE_CAD`. The build script `base_build.py` makes it from nothing; it reads skeleton P04's parameter list (`v2/01-CAD-Native/skeleton/pod_skeleton.py`, `PARAMS`, v4 since #94) at run time and adds those parameters under the same names, then BASE's own (`BASE_PARAMS`, each with its status and source). A BASE name the skeleton also defines is skipped, so the skeleton's value wins. The .f3d has no external links: it opens on its own.

The pod has no floor (D-132): the floor panels, their foam, F2's locator spigots and the threshold are gone. The base seal 118001 (a lip on the bands' inner faces, bought by the metre) is modelled as space envelopes, one body per run (`seal_runs`, `p02_seal_runs`): its plan rectangle on the room floor, `seal_t` into the pod, up to `seal_leg` above the band's bottom; the sill's door-end lip also has its fin under the plate, flush with the plate's outer face (`p02_seal_fins`). The parts list takes its metres from the runs, not from these bodies.

Every part is its own component, built in place in pod coordinates (`conventions.md` §4). Every sketch is fully constrained by dimensions driven by parameter expressions; the build fails if one isn't (`check_sketch`).

The same run also saves each part we make as its own design (`<PN>_P01_<NAME>_CAD`, with its .f3d here and its STEP in `v2/03-Manufacturing/base/`), and each subassembly as its own design (rebuilt and trimmed, not Save Copy As), for the drawings. A design it replaces is renamed `NAME_SUPERSEDED-<date>` in the cloud, never deleted (PM rule, 2026-11-01).

Rebuild (the assembly with the band part designs and the back band's subassembly design in one Fusion run, then the edit test in another; the loader reads the scripts only when the shared lock is granted):

```
python3 tools/fusion/run_script.py v2/01-CAD-Native/base/late_base.py --timeout 2700 \
  --arg targets=v2/01-CAD-Native/base/base_build.py --arg scope=p02 \
  --arg save=1 --arg replace=1 --arg export=1 --arg sub_list=band_b
python3 tools/fusion/run_script.py v2/01-CAD-Native/base/late_base.py --timeout 1200 \
  --arg targets=v2/01-CAD-Native/base/base_edit_test.py
python3 v2/03-Manufacturing/base/make_outputs.py --dxf      # needs ezdxf for the DXFs
```
