# Drawings the sample needs from Milestone 2

| Doc code | Revision | Status | Date |
|---|---|---|---|
| V2-SMP-WD (proposed) | P01 | DRAFT | 2026-10-31 |

The factory cuts nothing from this package's text: each item is built from a native Fusion drawing (guideline §4.4, §5, §6). The order follows the guideline: assembly before parts. Every drawing follows `conventions.md`: first-angle projection, `UNITS: mm`, 2D views and hole tables in X and Y only with the view's mapping to the pod's X/Y/Z, datums A/B/C from how the part is held, and the name `PARTNO_REV_DESCRIPTIVE-NAME_DWG.pdf`. Each comes with its native `.f3d` and a STEP (and DXF for flat parts) of the same revision. Part numbers come from the master BOM; none is assigned here. Every drawing stays at P01, DRAFT, until the PM releases it (conventions §8).

The Phase 0 proof drawing of a lower side panel (`v2/02-Drawings/proof/`) only tests the toolchain. It shows the old 20 × 20 welded steel frame with through-bolts, so the sample can't be built from it.
